 Data Cleaning Project – Layoffs Dataset

This project focuses on cleaning a layoffs.csv dataset using MySQL. The goal was to transform raw and inconsistent data into a clean, structured format ready for analysis.

 Tasks Performed

Removed duplicates to ensure each record is unique

Standardized data (trimmed text, fixed formatting, corrected inconsistencies)

Handled null and blank values appropriately

Removed unnecessary columns and rows

Converted date fields into proper SQL DATE format

 Objective

To practice real-world SQL data cleaning techniques and improve data quality for analysis.

 Skills Used

SQL Queries

Data Cleaning & Transformation

Window Functions (ROW_NUMBER)

Handling Missing Data in MySQL
